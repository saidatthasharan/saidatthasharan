## How I approach product building

1. Start with a clearly defined user problem and intended business outcome.
2. Convert the problem into requirements, user journeys, and prioritised increments.
3. Build a small, testable prototype and validate assumptions early.
4. Protect the codebase with version control, review, automated checks, and sensible access controls.
5. Treat security, data privacy, observability, and release readiness as product requirements.
